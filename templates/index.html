로봇-작업 관리 웹 애플리케이션

이 프로젝트는 Flask와 Pandas를 사용하여 로봇과 로봇에게 할당된 작업을 관리하는 간단한 웹 애플리케이션입니다. 데이터는 Excel 파일(Robot02.xlsx)에 저장됩니다.

🚀 주요 기능

  • 로봇 관리 (CRUD): 로봇 목록 조회, 추가, 수정, 삭제 (관련 작업 포함)
  • 작업 관리 (CRUD): 각 로봇에 할당된 작업 목록 조회, 추가, 수정, 삭제
  • 편의 기능: 검색 (로봇 이름, 모델, 작업 이름), 정렬 (로봇 이름 오름차순/내림차순), 페이지네이션

🛠️ 기술 스택

  • 백엔드: Python, Flask
  • 데이터 처리: Pandas
  • 데이터베이스: Microsoft Excel (.xlsx)
  • 프론트엔드: HTML, CSS (Bootstrap), Jinja2

⚙️ 설치 및 실행 방법

1. 필요한 라이브러리 설치

pip install Flask pandas openpyxl

2. 애플리케이션 실행

python app.py

3. 웹 브라우저에서 접속

실행 후 터미널에 나타나는 주소(기본값: http://127.0.0.1:5000)로 접속합니다. 최초 실행 시, 샘플 데이터가 포함된 Robot02.xlsx 파일이 자동으로 생성됩니다.
